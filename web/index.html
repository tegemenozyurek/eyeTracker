How it works›
  1. TrackMediaPipe finds 478 face points, 52 expression scores and the head's rotation in every frame
  2. Measureeye closure, blinks, PERCLOS over 60 s, yawns, head pose, time with the eyes off the road
  3. Decidethe selected model turns these into OK, Attention or Take a break
  4. Holdan alert steps down only after it has been gone for a few seconds, so it does not flicker
A learning project, not a safety system: never rely on it while driving. The camera feed is processed only on this device; no image or video is uploaded or stored.
